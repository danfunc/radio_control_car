機能とオーバーヘッドを削った組み込み向けのカーネルにファイルシステムなどの汎用高機能レイヤーを積み重ねることで、組み込み環境と汎用環境の双方でコードベースを共通化することを目指す自作OS「Shizuku」のデモンストレーション用コード

## 予備ファーム (いま車に載っている版)

新しいファームで動かなくなったとき、デバッグできなくなったときは、まずこれを書き戻せば走れる状態に戻ります。

- ファイル: `prebuilt/car_fallback_9fc34f7.uf2` (このリポジトリの 9fc34f7 を Pico 2 W 向けにビルドしたもの。2026-11-20 に車へ書き込んだ版。2026 年 3 月時点で遊べていた仕様)
- 確認: `shasum -a 256 -c prebuilt/car_fallback_9fc34f7.uf2.sha256`
- 書き方:
  1. `git pull` で最新を取る。
  2. Pico の BOOTSEL を押しながら USB を挿す (RP2350 ドライブが出る)。
  3. `picotool load -x -v prebuilt/car_fallback_9fc34f7.uf2` (複数台つないでいるときは末尾に `--ser <シリアル>`)。
     picotool が無ければ、出てきたドライブに uf2 をドラッグしてもよい。
- この版の仕様: **起動するたびにコントローラのシンクボタンを押してペアリングする** (保存した鍵を使わない)。
  接続相手のアドレスはソースに固定 (`CYW43_BL_DRIVER.cpp` の `REMOTE_BD_ADDR`)。BLE OTA は無い。
- 注意: 新しい版 (stage3 入り) を書いたあとに戻す場合は、書く前に `picotool erase -a` でフラッシュを全部消してから書くと確実。
